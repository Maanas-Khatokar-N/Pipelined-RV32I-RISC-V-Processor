# 5-Stage Pipelined RV32I RISC-V Processor
Implementation of a 5-stage pipelined RV32I RISC-V processor in Verilog with support for the base integer instruction set, pipelined execution, hazard handling, and memory interfacing.

Current status:
- Single-cycle processor completed
- 5-stage pipeline connected
- Pipeline verified using NOP-inserted programs
- Hazard detection and forwarding under development
